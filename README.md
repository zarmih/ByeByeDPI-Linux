# ByeByeDPI Linux

Это графический интерфейс (GUI) для [ByeDPI (ciadpi)](https://github.com/hufrea/byedpi), инструмента обхода DPI в Linux.
Данный проект представляет собой минимально жизнеспособный продукт (MVP), не требующий прав `root` (`sudo`) и не изменяющий системные маршруты, firewall или настройки DNS напрямую.

**Ограничения (Важно!)**
*   Это **НЕ** полноценный VPN.
*   Ваш реальный IP-адрес **НЕ** скрывается от посещаемых сайтов.
*   Системный трафик **ПОКА НЕ** перенаправляется автоматически (никаких TUN/nftables).
*   Вам необходимо **вручную** настроить ваш браузер или приложение на использование локального SOCKS5-прокси (обычно `127.0.0.1:1080`), который поднимает данная программа.

## Установка и запуск

1. Склонируйте репозиторий вместе с субмодулями (уже сделано в этом репозитории):
   ```bash
   # git clone --recursive <URL>
   ```
2. Соберите бинарный файл `ciadpi` (требуется `gcc` и `make`):
   ```bash
   cd vendor/byedpi
   make
   cd ../..
   ```
3. Инициализируйте локальное окружение Python (требуется установленный `uv`):
   ```bash
   ./bootstrap
   ```
4. Запустите приложение:
   ```bash
   ./dev-run
   ```
   *Скрипт `dev-run` автоматически выберет доступный графический frontend. **PySide6 (Qt)** является основным и приоритетным фронтендом (версия 6.11.1 успешно протестирована). Если он недоступен, будет использован нативный **GTK3 (PyGObject)** через системный Python. Если и GTK3 отсутствует, запустится минималистичный fallback **Tkinter**.*

  ## Библиотека Стратегий и Тестирование

  Для обеспечения наилучшего обхода блокировок в `PySide6` (основном интерфейсе) добавлена **Библиотека стратегий**.

  - **Источник:** Стратегии автоматически импортированы из официального Android-клиента [romanvht/ByeByeDPI](https://github.com/romanvht/ByeByeDPI) (файл `proxytest_strategies.list`).
  - **Количество:** Импортировано 60 оригинальных стратегий. Все они на 100% поддерживаются нашим ядром `ciadpi` в Linux.
  - **Upstream commit:** `ffda4fa93d94472217c75e51b45fdd18f966c0af`.
  - **Тестирование:** Встроенный инструмент позволяет протестировать выбранную стратегию или пакетно прогнать все. Результаты зависят от вашего провайдера. По завершении теста вы можете нажать **Select Best**, чтобы выбрать самую быструю и успешную стратегию.
  - **Обновление списка:** Вы можете обновить список стратегий из upstream в любой момент, выполнив скрипт `./scripts/update_strategies.py`. Он скачает новые данные и обновит локальный JSON, не затрагивая ядро программы.

  > **Внимание:** Fallback-интерфейсы (GTK3 и Tkinter) предоставляют базовый функционал и не содержат графической библиотеки стратегий. Вы по-прежнему можете использовать их с пользовательскими аргументами, но для полного функционала рекомендуется PySide6.

  ## Настройка браузера (на примере Firefox)

Поскольку программа работает как SOCKS5-прокси, вам нужно направить трафик браузера через неё:
1. Откройте **Настройки (Settings)** в Firefox.
2. Прокрутите в самый низ до **Параметры сети (Network Settings)** и нажмите **Настроить (Settings...)**.
3. Выберите **Ручная настройка прокси (Manual proxy configuration)**.
4. В поле **Хост SOCKS (SOCKS Host)** введите `127.0.0.1`, а в поле **Порт (Port)** — `1080` (или другой, если вы изменили его в аргументах).
5. Убедитесь, что выбран **SOCKS v5**.
6. **ОБЯЗАТЕЛЬНО** поставьте галочку **Использовать прокси DNS при использовании SOCKS v5 (Proxy DNS when using SOCKS v5)**.
7. Нажмите ОК.

*Чтобы вернуть настройки обратно, выберите "Без прокси" (No proxy).*
